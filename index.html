Content Refresh Opportunity Scoring using Historical Search Performance

Machine Learning Capstone – FlyRank Internship

Author: Sana Kamran

Abstract

This project investigates whether historical search performance can identify pages that should be prioritized for content refresh. A rule-based baseline and a Random Forest classifier were developed using the anonymized FlyRank internship dataset. Historical search signals including clicks, impressions, average search position, CTR and trend information were used as features. The results demonstrate that historical search signals can support prioritization decisions. The findings are intended as decision-support and do not imply causal improvement in search rankings.

1. Introduction / Problem Statement

Large websites contain thousands of pages, making manual review difficult. This project develops a simple content refresh scoring system using historical search performance. The objective is to identify pages that may benefit from editorial review.

2. Data

The analysis uses the anonymized FlyRank internship dataset (content_refresh_anonymized.csv). Historical search performance variables including clicks, impressions, average position, CTR and trend percentage were analyzed. Rows with missing values in the selected features were excluded where necessary. No client names, URLs, credentials or private search queries were used.

3. Methodology

  • Baseline scoring rule created from historical search performance.
  • Low clicks received +40 points.
  • Low impressions received +30 points.
  • Poor average position received +30 points.
  • Random Forest classifier trained using historical features.
  • No future-window information, product flags or label-derived variables were used.

The Random Forest classifier reproduced the baseline decision rule because the target variable was generated using the same historical scoring rule. These results demonstrate consistency with the baseline rather than improved predictive performance. The findings should therefore be interpreted as decision-support based on historical search signals.

5. Limitations

  • Target labels were rule-generated rather than editorial outcomes.
  • The project cannot demonstrate causal ranking improvement.
  • Seasonality and external ranking factors were not modeled.
  • Recommendations should support editorial decisions rather than replace them.

6. Ranked Recommendations

  1. Prioritize pages with low historical clicks.
  2. Review pages with low historical impressions.
  3. Improve pages with poor average search position.
  4. Review metadata and content quality.
  5. Monitor performance after refresh.
