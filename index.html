Content Refresh Opportunity Scoring using Historical Search Performance

Author: Sana Kamran

Abstract

This project investigates whether historical search performance signals can identify pages that should be prioritized for content refresh. A rule-based baseline and a Random Forest classifier were developed using anonymized FlyRank internship data. Historical search metrics including clicks, impressions, average position, CTR, and trend information were used for analysis. The resulting ranked recommendations are intended to support editorial decision-making rather than predict future ranking changes. All findings are presented as observational and decision-support evidence without claiming causal impact.

1. Introduction / Problem Statement

Content teams often manage thousands of pages and cannot manually review every page. This project investigates whether historical search performance can be used to prioritize pages for review. The objective is to identify content that may benefit from refreshing based on observed historical search signals.
